JavaScript Vanilla de activación (IntersectionObserver):
Pégalo al final de tu <body> o en un archivo .js. Detecta automáticamente los elementos con .reveal-on-scroll y les añade .is-revealed al entrar un 15% en pantalla:
Html
<script>
  document.addEventListener('DOMContentLoaded', () => {
    // Si el usuario prefiere movimiento reducido, no se aplica animación
    if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
      document.querySelectorAll('.reveal-on-scroll').forEach(el => el.classList.add('is-revealed'));
      return;
    }

    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          entry.target.classList.add('is-revealed');
          observer.unobserve(entry.target); // Revela una sola vez con fluidez
        }
      });
    }, {
      rootMargin: '0px 0px -60px 0px',
      threshold: 0.12
    });

    document.querySelectorAll('.reveal-on-scroll').forEach(el => observer.observe(el));
  });
</script>
Ejemplo de uso en el HTML:
Html
<!-- Sección que sube al hacer scroll -->
<section class="reveal-on-scroll reveal-fade-up">
  <h2>¿En qué podemos ayudarle?</h2>
  <div class="servicios-grid">
    <!-- Tarjetas que aparecen en cascada (stagger) -->
    <div class="card reveal-on-scroll reveal-fade-up delay-1">Dirección de proyectos</div>
    <div class="card reveal-on-scroll reveal-fade-up delay-2">Ingeniería eléctrica</div>
    <div class="card reveal-on-scroll reveal-fade-up delay-3">Ingeniería multidisciplinar</div>
    <div class="card reveal-on-scroll reveal-fade-up delay-4">Consultoría</div>
  </div>
</section>
